# Almosafer Final Project

## 📌 Overview
A full-stack web application for managing travel bookings and reservations. The system allows users to browse, book, and manage trips efficiently.

---

## 🛠 Technologies Used
- Frontend: React.js
- Backend: Node.js
- Database: MySQL
- Tools: Git, GitHub

---

## 🚀 Features
- User authentication (login system)
- Travel booking and reservation management
- Data storage and retrieval using MySQL
- Responsive user interface
